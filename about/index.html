About Passalong

Worksheets that fit in a file of about 23 KB, work offline on any phone, and send answers back as a short code by SMS.

Who it is for

  • Learner: a Grade 7 learner in rural Kenya who does homework on a parent's shared Android phone with prepaid data.
  • Barrier: the worksheet arrives as a scanned PDF. It costs data to download, cannot be answered on the phone, gives a screen reader nothing to read, and the teacher gets nothing back.
  • Change: the same worksheet as one file of about 23 KB that works in airplane mode. The learner checks each answer and gets feedback for the mistake they made. Their first answers go back to the teacher as a 12-character code in one text message.

Our scan of the six sample questions, made with a phone's document scanner, was 2,165,971 bytes. The Passalong file for the same questions is 23,104 bytes, about 94 times smaller.

Privacy

Passalong has no server and no accounts. A worksheet lives in its link or its file. Answers stay on the learner's phone until the learner chooses to send the code. The code holds an optional class number and the first answer to each question. It holds no name. Nothing is tracked.

The site makes no requests to anyone else: no analytics, fonts or cookies. All the examples use a made-up worksheet, invented class numbers and the made-up number +254 700 000 000.

People tests: six people who had not worked on Passalong each did the sample worksheet on their own phone and sent the code (15 Nov). All six finished and sent a code with no help, and nothing confused them. All six said the screens could look much better, the fonts included. Their names, phones, answers and codes were not kept.

Not tested: switch access, a Braille display, and a real 2G network. An iPhone and an older Android phone were also used (15 Nov), but their models were not recorded. Automated tools find only some accessibility problems, so their scores are not a pass on their own.

Limitations

  • Text only: no images, diagrams or maths notation beyond plain text such as 3/4 and x².
  • The screens are in English and nothing is read aloud. The worksheet itself can be in any language.
  • Up to 20 questions per worksheet, and one correct option per question. No QR codes.
  • The code carries only each learner's first answer and whether they opened the hint, not their later tries.
  • Codes can be forged and a worksheet file can be edited before it is passed on. Passalong is for practice, not exams.
  • A code checked against the wrong worksheet is caught 4,095 times in 4,096.
  • A link works offline only after it has been opened once with a connection. A downloaded file works offline from the start.
  • If storage is blocked, for example in some file viewers, answers are lost when the page closes.
  • On a shared phone, a learner's answers stay on the phone until someone chooses "Next learner on this phone".
