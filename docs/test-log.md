# Test log

What was tested, how, on what, and what happened. A test that failed or was not run stays here, marked as such. Nothing here says "fully accessible": it says what Passalong was tested with and what it was not tested with.

All test data is made up: the sample worksheet in `src/core/sample.ts` and invented class numbers. People who helped test are not named, and their answers and codes are not kept.

Last updated: 15 Nov 2026 (people tests and Wednesday's gate).

## Known issues

- None open.
- Fixed 15 Nov: the learner's code was spoken through an `aria-label` on a paragraph, which ARIA does not allow, so a screen reader might have read the code as one word (row 3). Found by axe. The visible code is now hidden from screen readers, and a hidden copy spells it out one character at a time. Heard one character at a time with VoiceOver on a Mac (row 2); not yet with TalkBack (row 3).

## Not tested

- Phones are named only where the model was recorded: the Galaxy A06 in check 3. The phones in checks 4 to 7 and rows 3 and 13 were not written down.
